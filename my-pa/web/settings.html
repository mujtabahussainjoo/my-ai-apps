Blank keys preserve saved credentials. Use {env:VARIABLE_NAME} to read a key from the server environment. Entering a key saves it in your private local configuration file.

Agent tool rules

Local agent tools are enabled by default. File tools stay within the workspace; commands run with the server user’s filesystem and network access. Use read, write, shell, web or a tool name to restrict actions. Deny and ask both block execution. Later matching rules take precedence.
